# ETF brokerage readiness

For Coinbase brokerage connection, holdings-access or setup questions, report the deterministic connection-readiness evidence. The readiness check is local to the runtime, not an AgentCore Gateway tool. Never present research-wallet credentials as brokerage authorization. No authenticated account holdings or ETF eligibility are known until independently verified. Coinbase isolated agent portfolios are documented for spot crypto only; ETF account isolation must be verified separately.

Order drafts are proposals using reference prices, not executable Coinbase quotes. Existing live-order refusals remain active. User consent, approved connection, account-specific ETF eligibility, operational limits and a separate execution activation are required before live orders. Keep all tokens outside messages and checkpoints. This skill does not itself provide a remote tool or grant permissions.
