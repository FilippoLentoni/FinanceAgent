## Why

The beta comparison needs recurring EC2 model invocations and inspectable exact
inputs across durable hourly slots. Existing interactive sessions and report
timestamps cannot demonstrate that these financial workflows actually ran.

## What Changes

- Add separate persistent minute Codex snapshot, thirty-minute Codex research,
  hourly comparison, New York end-of-day and rolling weekly systemd timers.
- Add locks, bounded deadlines, permanent slot health receipts, failure visibility
  and missed-hour accounting through the authoritative experiment backend.
- Add beta machine-only LangGraph input capture before provider/tool invocation,
  synchronously persisted through the existing immutable activity interface.
- Pin compatible contracts 1.12.0 without changing user portfolio confirmation,
  financial budgets, provider/token caps or higher-environment access.
- Add beta-only deployment monitor that holds Gamma and restores its transition
  only after the explicit-source execution has stopped.

## Capabilities

### New Capabilities
- `beta-modeling-jobs`: durable EC2 financial workflow execution and receipts.

### Modified Capabilities
None.

## Impact

FinanceAgent EC2 operator code and opt-in beta machine invocation response gain
public input evidence. No brokerage API, transfer or production approval is used.
The graph stays LangGraph and its delegated numerical allocation remains labeled
with the actual served policy. Runtime provider and tool caps still apply.
