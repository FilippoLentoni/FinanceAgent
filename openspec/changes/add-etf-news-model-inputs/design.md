# Design

Keep one canonical local procurement ledger, fixed reviewed BlockRun endpoint/recipient, exact Base USDC and USD 0.03 per-call ceiling. Add ETF_MARKET as a fixed profile, retaining crypto receipts and no new budget. Collect shared macro/ETF metadata once per hourly slot during regular NY market hours using an expiring operator-host timer. Central ingestion receives title/URL/publication timestamps, actual retrieval/availability timestamps and payment/delivery checksums; it does not receive private payment proof or wallet state. A separate publish action replays completed receipts without purchasing. Bound raw response and sanitize output, respect explicit provenance and quarantine until quality/rights validation. Training remains ineligible without historical licensed corpus. New MCP input tool is integrated through existing classical Gateway and LangGraph skill; all numerical claims continue through evidence checks. Deployment remains beta-only under the existing USD 100 AWS cap. Paper records operational/model-input evidence without inferring accuracy gains.
